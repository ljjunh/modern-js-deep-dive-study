# 08 제어문

- 조건에 따라 코드 블록을 실행(조건문)하거나 반복 실행(반복문)할 때 사용
- 코드의 실행 흐름을 인위적으로 제어
- 고차 함수를 사용한 함수형 프로그래밍 기법에서는 제어문의 사용을 억제하여 복잡성을 해결하려고 노력

## 8.1 블록문

- 0개 이상의 문을 중괄호로 묶은 것
- 코드 블록 or 블록
- 블록문은 자체 종결성으로 끝에는 세미콜론 붙이지 않음

## 8.2 조건문

- 주어진 조건식의 평가 결과에 따라 코드 블록(블록문)의 실행 결정
- 조건식: 불리언 값으로 평가될 수 있는 평가식

### 8.2.1 `if ... else`문

- `else if`, `else` 는 옵션
- `if`, `else` 는 한 번만 사용
- 조건에 따라 단순히 값을 결정하여 변수에 할당할 경우는 삼항 조건 연산자 사용이 가독성 좋음
- 조건에 따라 실행해야 할 내용이 복잡 -> 여러 줄의 문이 필요할때 유용
- 논리적 참, 거짓으로 실행할 코드 블록 결정

### 8.2.2 `switch`문

- 표현식을 평가, 일치하는 표현식 없다면 default 문으로 이동(선택사항)
- switch 문의 표현식은 불리언 값보다는 문자열이나 숫자 값인 경우 많음
- 폴스루: 일치하는 case 문 이후의 모든 case 문과 default 문 실행
- 조건이 너무 많아 if ... else 보다 가독성 좋은 경우 사용
- 다양한 상황(case)에 따라 실행할 코드 블록 결정

## 8.3 반복문

- 조건식의 평가 결과가 참인 경우 코드 블록 실행, 조건식이 거짓일 때까지 반복

### 8.3.1 for 문

- for 문의 변수 선언문, 조건식, 증감식은 모두 옵션
  - `for( ;; ){ ... } // 무한 루프`
- 반복 횟수가 명확할 때 주로 사용

### 8.3.2 while 문

- 반복 횟수가 불명확할 때 주로 사용

### 8.3.3 do while 문

- 코드 블록을 먼저 실행하고 조건식 평가

## 8.4 break 문

- 레이블 문, 반복문(for, for...in, for...of, while,do...while) 또는 switch 문의 코드 블록 탈출

- 레이블 문: 식별자가 붙은 문, 중첩된 for 문 외부로 탈출할 때 유용하지만, 그 밖의 경우에는 권장 하지 않음
  - 프로그램 흐름 복잡 -> 가독성이 나빠지고 오류를 발생시킬 가능성 높아짐

## 8.5 continue 문

- 반복문의 코드 블록 실행을 중단하고, 반복문의 증감식으로 실행 흐름 이동
- if 문 내에서 실행해야 할 코드가 길다면 continue 문 사용 고려
