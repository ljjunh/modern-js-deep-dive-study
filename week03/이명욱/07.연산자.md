# 07 연산자

## 7.1 산술 연산자

- 수학적 계산으로 새로운 숫자 값
- 산술 연산이 불가능한 경우, NaN 반환

### 7.1.1 이항 산술 연산자

- 부수 효과 X (피연산자의 값 변경 X)
- `+`, `-`, `*`, `/`, `%`

### 7.1.2 단항 산술 연산자

#### 증가/감소 연산자 (`++`, `--`)

- 부수 효과 O (피연산자의 값 변경 O)
- 전위/후위 증감 연산자

#### `+`, `-`

- 숫자 타입이 아닌 피연산자 숫자 타입으로 변환하여 반환
- 부수 효과 X

### 7.1.3 문자열 연결 연산자

- `+` 연산자는 피연산자 중 하나 이상이 문자열인 경우 문자열 연결 연산자로 동작
- 개발자의 의도와는 상관없이 자바스크립트 엔진에 의해 암묵적으로 타입이 자동 변환
- 암묵적 타입 변환, 타입 강제 변환

## 7.2 할당 연산자

- 우항의 피연산자의 평가 결과를 좌항의 변수에 할당
- 부수 효과 O
- `=`, `+=`, `-=`, `*=`, `/=`, `%=`
- 할당문: 표현식(값으로 평가될 수 있는 문)인 문(프로그램을 구성하는 기본 단위이자 최소 실행 단위)

## 7.3 비교 연산자

- 좌항과 우항의 피연산자를 비교한 다음 불리언 값으로 반환

### 7.3.1 동등/일치 비교 연산자

#### 동등 비교 (`==`)

- 암묵적 타입 변환을 통해 타입 일치시킨 후 같은 값 비교
- 예측하기 어려운 결과를 만들어 냄

#### 일치 비교 (`===`)

- 타입도 같고 값도 같은 경우에 `true` 반환
- NaN은 자신과 일치하지 않는 유일한 값, `Number.isNaN`으로 판별
- `+0 === -0`도 true 반환, `Object.is`로 판별 가능

## 7.4 삼항 조건 연산자

- 조건식의 평가 결과에 따라 반환할 값 결정
- 부수 효과 X
- 값처럼 사용할 수 있음! (= 표현식인 문)
  - but, `if ... else` 문은 값처럼 사용 X

## 7.5 논리 연산자

- 논리 부정(`!`) 연산자는 언제나 불리언 값 반환
- 논리합(`||`), 논리곱(`&&`) 연산자 표현식의 평가 결과는 불리언 값이 아닐 수 있음.
  - e.g. `'Cat' && 'Dog' // 'Dog'` (단축 평가)

## 7.8 typeof 연산자

- 'string', 'number', 'boolean', 'undefined', 'symbol', 'object', 'function'
- 7개의 데이터 타입과 정확하게 일치 X
- `typeof null // 'object' `, 자바스크립트 첫 번째 버전의 버그
  - `null` 확인 시에는 일치 연산자(`===`) 사용
- 선언하지 않은 식별자 `undefined` 반환

## 7.9 지수 연산자

- `2 ** 3` = `Math.pow(2, 3)`
- 음수가 밑일 경우 괄호 필수 `(-5) ** 2`
- 할당 연산자와 사용 가능 `**=`
- 이항 연산자 중에서 우선순위 가장 높음
