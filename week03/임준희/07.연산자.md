### 연산자

- 연산자는 하나 이상의 표현식(피연산자)을 받아 하나의 값을 만든다. 피연산자는 값으로 평가될 수 있는 표현식이어야 하고, 연산자와 피연산자를 조합한 연산자 표현식도 표현식이다.
- 피연산자가 명사(값)라면 연산자는 동사(값을 만드는 동작)다.

### 산술 연산자

- 이항 산술 연산자는 두 피연산자로 새 숫자 값을 만든다. 연산자 자체는 피연산자를 바꾸지 않는다.
- 산술이 불가능하면 NaN이 된다. (예외: 1/0 = Infinity, BigInt와 Number를 섞거나 Symbol을 쓰면 NaN이 아니라 TypeError)
- +는 두 피연산자를 원시 값으로 바꾼 뒤 그중 문자열이 있으면 연결, 없으면 덧셈

### 할당 연산자

- 우항의 값을 좌항 변수에 넣는다. 변수 값이 바뀌는 부수 효과가 있다.
- 할당 표현식은 할당된 값으로 평가된다.(ex console.log(x = 10)은 10)

### 비교 연산자

- ==(동등)은 타입을 변환한 뒤 비교하고, ===(일치)는 타입과 값이 모두 같아야 true
- NaN은 자기 자신과도 일치하지 않는 유일한 값이다. 그래서 NaN을 판별할때는 Number.isNaN을 사용
- 0 === -0은 true. 둘을 구분하려면 Object.is
- 대소 비교는 둘 다 문자열이면 문자 코드 순으로, 아니면 숫자로 바꿔 비교한다. "10" < "9"는 true.

### 삼항 조건 연산자

- 자바스크립트의 유일한 삼항 연산자. 조건이 truthy면 두 번째, falsy면 세 번째 피연산자로 평가된다.
- if...else는 문이라 값으로 쓸 수 없고, 삼항 연산자는 표현식이라 값 자리에 올 수 있다.

### 논리 연산자

- !는 항상 불리언을 반환한다. 피연산자가 불리언이 아니면 변환한다.
- ||, && 두 피연산자 중 하나를 그대로 돌려주므로 결과가 불리언이 아닐 수 있다. 왼쪽만으로 결과가 정해지면 오른쪽은 평가하지 않는다.

### 쉼표 연산자

- 왼쪽부터 차례로 평가하고 마지막 피연산자의 값을 돌려준다.

### 그룹 연산자

- 소괄호로 묶은 표현식이 가장 먼저 묶인다. 우선순위 조절에 사용한다.

### typeof 연산자

- 피연산자의 타입을 문자열로 돌려준다. 현재 8가지: string, number, boolean, undefined, symbol, bigint(ES2020), object, function
- typeof null은 "object"다. 첫 버전의 버그가 하위 호환 때문에 남았다. null 판별은 typeof 대신 === null 사용
- 선언하지 않은 식별자에 typeof를 쓰면 ReferenceError가 아니라 "undefined"
- typeof 결과는 언어 타입과 1:1이 아니다. "function"은 호출 가능한 Object에 붙는 이름이다.

### 지수 연산자

- ES7에서 도입. 이전에는 Math.pow 사용

## ==는 예측 불가능한가?

IsLooselyEqual을 따라가면 전부 설명된다.
IsLooselyEqual(x, y)의 단계를 순서대로 옮기면 이렇다. 위에서부터 처음 걸리는 규칙 하나만 적용된다.

1. 두 피연산자의 타입이 같으면 '==='와 같은 방식으로 비교하고 끝
2. null과 undefined 조합이면 -> true
3. Number vs String -> String을 ToNumber 한 뒤 다시 ==로 비교
4. BigInt vs String -> String을 BigInt로 바꾼 뒤 다시 ==로 비교
5. 한쪽이 Boolean -> 그 Boolean을 ToNumber 한 뒤 다시 ==로 비교
6. 원시 값 vs Object -> Object를 ToPrimitive 한 뒤 다시 ==로 비교
7. BinInt vs Number -> 수학적 값이 같으면 true
8. 그 외 -> false
   책에 나온 예제로 확인해보자
   식: '0' == ''
   걸리는 단계: 1 (둘 다 String)
   결과: false

식: 0 == ''
걸리는 단계: 3
진행: '' -> 0, 0 == 0
결과: true

식: false == 'false'
걸리는 단계: 5
진행: false -> 0, 0 == 'false' -> 3단계 'false' -> NaN, 0 == NaN
결과: false

식: false == null
걸리는 단계: 5
진행: false -> 0, 0 == undefined -> 다시 1단계부터 돌면 아무것도 안걸림 -> 8단계
결과: false
