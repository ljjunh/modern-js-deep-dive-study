### 제어문

- 제어문은 조건에 따라 코드 블록을 실행하거나 반복할 때 쓴다. 코드는 기본적으로 위에서 아래로 실행되는데, 제어문은 이 흐름을 인위적으로 바꾼다.
- 흐름이 바뀌면 코드를 읽기 어려워진다. forEach, map, filter, reduce 같은 고차 함수는 제어문 사용울 줄여 이 복잡성을 낮추려는 시도다.

### 블록문

- 0개 이상의 문을 중괄호로 묶은 것. 자바스크립트는 블록문을 하나의 실행 단위로 다룬다.
- 블록문 끝에는 세미콜론을 붙이지 않는다. 자체 종결성을 갖기 때문이다.
- 블록은 실행 컨텍스트를 만들지 않고, 현재 컨텍스트의 LexicalEnvironment만 새 것으로 바꿨다가 나올 때 되돌린다. let/const/class는 이때 블록에 등록되고 var는 블록을 무시한다.

### 조건문

- 조건식의 평가 결과에 따라 블록 실행을 결정한다. 조건식이 불리언이 아니면 ToBoolean으로 암묵적 변환된다.

### if...else

- 참이면 if 블록, 거짓이면 else 블록. else는 옵션
- 사양 문법에는 else if라는 형태가 없다. else if는 else 뒤에 또 하나의 if문이 온 것이다. 그래서 else if를 여러 번 쓸 수 있다는 말은 if문을 중첩할 수 있다는 뜻이다.
- 블록 안의 문이 하나면 중괄호를 생략할 수 있다.

### switch

- 표현식을 평가한 값과 일치하는 case로 흐름을 옮긴다. 일치 여부는 일치연산자(===)로 판정한다.
- 매칭된 case를 실행한 뒤 break가 없으면 switch를 벗어나지 않고 다음 case들을 계속 실행한다. 풀스루를 의도적으로 써서 여러 case를 하나로 묶을 수도 있다(윤년 예제)
- switch 본문 전체가 하나의 블록 스코프다. 서로 다른 case에 같은 이름의 let을 쓰면 SyntaxError다.

### 반복문

- 조건식이 참인 동안 블록을 반복 실행한다. for, while, do...while 세 가지. 배열은 forEach, 객체 프로퍼티는 for...in, 이터러블은 for...of로 대체할 수 있다.

### for

- 실행 순서는 초기화(한번)->조건식->블록->증감식->조건식-> ....
- 조건식이 false가 되면 종료
- 중첩이 가능하고 안쪽 for에서 break하면 안쪽만 탈출한다.

### while

- 조건식이 참이면 계속 반복한다. 반복 횟수가 정해져 있으면 for, 불명확하면 while 사용
- while(true)는 무한루프라서 안에서 if + break로 탈출한다.

### do...while

- 블록을 먼저 실행하고 조건을 평가한다.
- 최소 한 번은 실행된다.

### break

- 레이블 문, 반복문, switch 문의 블록을 탈출한다.

### continue

- 반복문의 현재 회차를 중단하고 다음 회차로 넘어간다.
