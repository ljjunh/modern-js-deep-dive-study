# 제어문

제어문을 사용하면 코드의 실행 흐름을 인위적으로 제어할 수 있다.

- 하지만 코드의 실행 순서가 변경되면 직관적인 코드 흐름을 해쳐 가독성이 떨어진다.
- 이는 오류의 원인이 될 수 있으므로, 이후 고차 함수(`forEach`, `map`, `filter`, `reduce`)를 사용해 제어문 사용을 줄여 복잡성을 해결한다.

## 블록문

- 0개 이상의 문을 중괄호로 묶은 것이다.
- 블록문 끝에는 세미콜론을 붙이지 않는다. 블록문은 언제나 문의 종료를 의미하는 자체 종결성을 갖기 때문이다.

## 조건문

### if...else

- 조건식의 평가 결과에 따라 실행할 코드 블록을 결정한다.
- 조건식이 불리언 값이 아니면 암묵적 타입 변환에 의해 불리언 값으로 변환된다.
- 대부분의 if...else 문은 삼항 조건 연산자로 바꿔 쓸 수 있다.
  - 삼항 조건 연산자는 값으로 평가되는 표현식이라 변수에 할당할 수 있지만, if...else 문은 표현식이 아닌 문이라 할당할 수 없다.
  - 조건이 단순하면 삼항 조건 연산자, 복잡하면 if...else 문을 쓰는 것이 가독성에 좋다.

### switch

- 논리적 참/거짓보다는 다양한 case에 따라 실행할 코드 블록을 결정할 때 사용한다.
- 폴스루(fall through): 일치하는 case의 코드를 실행한 후 switch 문을 탈출하지 않고, 이후의 모든 case와 default까지 실행하는 것
- 각 case 끝에 break를 사용해 switch 문을 탈출하면 폴스루를 막을 수 있다.
  - 마지막 default에는 break를 생략하는 것이 일반적이다.

## 반복문

- 조건식의 평가 결과가 참인 동안 코드 블록을 반복 실행한다. 조건식은 반복할 때마다 다시 평가된다.
- 반복문을 대체할 수 있는 기능
  - 배열 순회: `forEach` 메서드
  - 객체 프로퍼티 열거: `for...in` 문
  - 이터러블 순회: `for...of` 문

### for 문

- 조건식이 거짓으로 평가될 때까지 코드 블록을 반복 실행한다.
- 반복 횟수가 명확할 때 주로 사용한다.
- 변수 `i`는 반복을 뜻하는 iteration의 약자다.
- 변수 선언문, 조건식, 증감식은 모두 생략 가능하다.
  - 조건식을 생략하면 무한루프가 된다. (`for (;;) {}`)
- 중첩해서 사용할 수 있다.

### while 문

- 조건식이 참이면 코드 블록을 계속 반복 실행한다.
- 반복 횟수가 불명확할 때 주로 사용한다.
- 조건식의 평가 결과가 불리언 값이 아니면 암묵적 타입 변환으로 불리언 값으로 변환한다.

### do...while 문

- 코드 블록을 먼저 실행한 후 조건식을 평가한다.
- 따라서 코드 블록은 최소 한 번 이상 실행된다.

### break 문

- 레이블 문, 반복문, switch 문의 코드 블록을 탈출한다.
- 이 외의 곳에서 사용하면 SyntaxError(문법 에러)가 발생한다.
- 레이블 문: 식별자가 붙은 문
  - 중첩된 for 문에서 break는 내부 for 문만 탈출하므로, 외부 for 문까지 한 번에 탈출할 때 레이블 문을 사용한다.
  - 그 외의 경우에는 흐름이 복잡해져 가독성이 나빠지고 오류 가능성이 높아지므로 권장하지 않는다.

### continue 문

- 반복문의 코드 블록 실행을 현 지점에서 중단하고, 반복문의 증감식으로 실행 흐름을 이동시킨다.
  - 증감식이 없는 while 문에서는 조건식으로 이동한다.

```javascript
  for (let i = 0; i < 5; i++) {
    if (i === 2) continue; // 아래 코드를 실행하지 않고 바로 i++로 이동
    console.log(i);
  }
```

- early return처럼 조건에 맞지 않으면 바로 다음 반복으로 넘어갈 수 있어서, if 문 안의 코드가 길어질수록 continue를 쓰는 편이 가독성이 좋다.
