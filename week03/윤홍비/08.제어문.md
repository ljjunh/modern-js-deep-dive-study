제어문을 사용하면 코드의 실행 흐름을 인위적으로 제어한다.

- 하지만 코드의 실행 순서가 변경되는 것은 직관적인 코드의 흐름을 혼란스럽게 한다. 따라서 가독성이 좋지 않다.
- 이는 오류를 발생시키므로 나중에 고차 함수(forEach, map, filter, reduce)를 사용해 제어문을 최소화하여 복잡성을 해결한다.

## 블록문

- 0개 이상의 문을 중괄호로 묶는다
- 블록문의 끝에는 세미콜론을 붙이지 않는다. 항상 문의 종료 의미를 가지고 있기 때문이다.

## 조건문

- if else
  - if else로 실행할 코드 블록을 결정한다.
  - if문의 조건식이 불리언 값이 아니라면 암묵적 타입 변환에 의해 불리언 값으로 변환된다.
  - 대부분의 if else는 삼항 조건 연산자로 바꿔 쓸 수 있다.
    - 하지만 삼항 조건 연산자 표현식은 값처럼 사용이 가능해 변수에 할당이 가능하나 if else는 할당이 되지 않는다.
    - 단순한 조건이면 삼항 연산자, 복잡하다면 if else를 쓰는 것이 좋다.
- switch
  - switch는 논리적 참거짓 보다는 case에 따라 실행할 코드 블럭을 정한다.
  - 폴스루(fall through) : 조건이 맞는 코드블록으로 이동해 실행한 것은 맞지만 실행 후 switch문을 탈출하지 않고 이후의 모든 case문과 default를 실행하는 것
  - break를 사용해 코드 블럭으로 탈출하여 폴스루를 막자

## 반복문

- 조건식이 거짓일때까지 코드 블럭을 실행한다.
- 반복횟수가 명확할때 사용한다.
- 반복문 대체 메서드
  - 배열 순회 : forEach
  - 객체 프로퍼티 열거 : for...in
  - 이터러블 순회 : for ... of
- for i
  - 조건식이 거짓으로 평가될 때까지 코드블럭 반복 실행
  - i 변수 의미는 반복을 뜻하는 iteration의 약자다
  - for 문의 변수 선언, 조건식, 증감식은 모두 옵션이다. (필수값 아님)
    - 만약 어떤 식도 선언하지 않는다면 무한루프가 된다. for (;;) {}
  - 중첩 가능하다.
- while 문
  - 조건식이 참이면 계속 반복 실행한다.
  - 반복횟수가 불명확할때 사용한다.
  - 조건식의 평가 결과가 불리언 값이 아니면 강제 타입 변환한다.
- do ... while 문
  - 코드 블럭을 일단 실행하고 조건식을 평가한다.
- break 문
  - 레이블 문, 반복문, switch문의 코드 블럭을 탈출한다.
  - 이외에 사용 시 SyntaxError(문법 에러)가 발생한다.
  - 레이블 문 : 식별자가 붙은 문
    - 중첩된 for 문의 내부 for 문에서 외부 for문을 탈출할 때 사용한다.
    - 그 외의 사용은 가독성을 해치고 오류 발생률이 높아지므로 권장하지 않는다.
- continue 문
  - 코드 블록 실행을 중단하고 증감식으로 실행 흐름을 이동시킨다.
    ```javascript
    for (let i = 0; i < 5; i++) {
      if (i === 2) continue; // 여기서 아래 코드 실행 안 하고 바로 i++로 이동
      console.log(i);
    }
    ```
  - early return과 같이 조건에 안맞으면 다음 실행으로 바로 넘어갈 수 있으므로, 조건문 안 코드가 길어질수록 continue를 쓰는 것이 가독성이 좋다.
