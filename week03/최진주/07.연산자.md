# 7장. 연산자

## 1. 연산자란

- 피연산자(operand, 오퍼랜드)를 연산해 새로운 값을 만드는 문법
- 연산자 + 피연산자 조합도 하나의 값으로 평가되는 표현식
- 주요 종류

| 종류 | 연산자 | 이름 |
|---|---|---|
| 산술 | `+ - * / % ++ --` | 산술 연산자 |
| 할당 | `= += -= *= /= %= **=` | 할당 연산자 |
| 비교 | `==` / `===` / `!=` / `!==` | 동등 / 일치 / 부동등 / 불일치 비교 연산자 |
| 대소 비교 | `> < >= <=` | 대소 관계 비교 연산자 |
| 조건 | `조건 ? a : b` | 삼항 조건 연산자 |
| 논리 | `!` / `&&` / `\|\|` | 논리 부정(NOT) / 논리곱(AND) / 논리합(OR) 연산자 |
| 기타 | `typeof`, `**`, `,`, `( )` | 타입 확인 / 지수 / 쉼표 / 그룹 연산자 |

---

## 2. 산술 연산자

### 이항 산술 연산자 `+ - * / %`

- 피연산자 2개 필요
- 원본 값 변경 없음 (부수 효과 없음)

### 단항 산술 연산자 `++ -- + -`

- `++`, `--`는 피연산자 값을 직접 변경 (부수 효과 있음)
- 전위(`++x`): 먼저 증가, 증가한 값으로 평가
- 후위(`x++`): 증가 전 값으로 평가, 이후 증가
- 두 경우 모두 x 자체는 증가

```js
let x = 5, result;
result = x++; // result 5, x 6
result = ++x; // result 7, x 7
```

- 단항 `+`: 숫자로 변환한 값 반환, 원본 변경 없음
- 단항 `-`: 숫자로 변환 후 부호 반전

```js
+'10';    // 10
+true;    // 1
+'hello'; // NaN
```

### 문자열 연결 연산자

- `+`는 피연산자 중 하나라도 문자열이면 문자열 연결로 동작
- 그 외에는 산술 연산, 이때 암묵적 타입 변환 발생
- 암묵적 타입 변환: 개발자 의도와 무관하게 엔진이 타입을 자동 변환하는 것

```js
'1' + 2;       // '12'
1 + true;      // 2   (true → 1)
1 + null;      // 1   (null → 0)
1 + undefined; // NaN (undefined → NaN)
```

## 3. 할당 연산자

- 할당문은 할당한 값으로 평가되는 표현식인 문
- 표현식인 문: 표현식이면서 그 자체로 문이 되는 것 (예: `x = 1;`)
- 연쇄 할당 가능, 오른쪽에서 왼쪽으로 평가

```js
let a, b, c;
a = b = c = 0; // c → b → a 순서로 0 할당
```

## 4. 비교 연산자

| | `==` 동등 비교 | `===` 일치 비교 |
|---|---|---|
| 비교 방식 | 암묵적 타입 변환 후 값 비교 | 타입과 값 모두 비교 |
| 결과 예측 | 어려움 | 쉬움 |
| 실무 | 사용 지양 | 기본으로 사용 |

```js
5 == '5';  // true
5 === '5'; // false
0 == '';   // true  (예측하기 어려운 결과)
'0' == ''; // false
```

- `===`의 예외 두 가지
  - `NaN`(낸)은 자기 자신과도 불일치 → `Number.isNaN()`으로 확인
  - `0 === -0`은 true
- `Object.is()`로 두 예외 정확히 구분 가능

```js
NaN === NaN;          // false
Number.isNaN(NaN);    // true
Object.is(NaN, NaN);  // true
Object.is(0, -0);     // false
```

## 5. 삼항 조건 연산자

- 형태: `조건식 ? 참일 때 값 : 거짓일 때 값`
- 조건식이 불리언이 아니면 불리언으로 암묵적 변환

| | 삼항 조건 연산자 | if...else |
|---|---|---|
| 성격 | 값으로 평가되는 표현식 | 값으로 평가되지 않는 문 |
| 할당, return, JSX 등 값 자리 | 사용 가능 | 사용 불가 |

```js
const label = isPaid ? '결제 완료' : '결제 대기'; // 가능

// if...else는 값 자리에 둘 수 없어 변수에 따로 담아야 함
let label2;
if (isPaid) label2 = '결제 완료';
else label2 = '결제 대기';
```

## 6. 논리 연산자

### 읽는 법

| 연산자 | 이름 | 읽는 법 | 비유 |
|---|---|---|---|
| `!` | 논리 부정 (NOT, 낫) | ~가 아니다 | 뒤집기 |
| `&&` | 논리곱 (AND, 앤드) | ~도 ~도, 둘 다 | 자물쇠 2개, 둘 다 열어야 통과 |
| `\|\|` | 논리합 (OR, 오어) | ~나 ~, 하나라도 | 입구 2개, 아무 데로나 통과 |

- `!a && !b`: a도 아니고 b도 아님 (둘 다 아니어야 true)
- `!a || !b`: a가 아니거나 b가 아님 (하나만 빠져도 true)
- 조건을 "전부 통과해야 하는 필터"로 생각했다면 `&&`에 해당

### 반환 규칙

- `!`만 항상 불리언 반환
- `&&`, `||`는 불리언이 아닌 피연산자의 원래 값을 그대로 반환
- 논리 연산 결과를 결정한 피연산자를 반환하는 방식 (단축 평가, 9장에서 상세)

| 연산자 | 앞이 truthy일 때 | 앞이 falsy일 때 |
|---|---|---|
| `&&` | 뒤를 계산해서 그 값 그대로 반환 | 앞을 반환 (뒤는 계산 안 함) |
| `\|\|` | 앞을 반환 (뒤는 계산 안 함) | 뒤를 계산해서 그 값 그대로 반환 |

- truthy(트루시): 불리언 문맥에서 true로 취급되는 값
- falsy(폴시): 불리언 문맥에서 false로 취급되는 값
  - `false`, `0`, `-0`, `''`, `null`, `undefined`, `NaN`, `0n`
- falsy는 false로 "취급"될 뿐 값 자체가 false로 바뀌지 않음
- `&&`는 앞이 truthy면 뒤의 truthy 여부를 판정하지 않고 뒤 값 자체를 반환

```js
'Cat' && 'Dog'; // 'Dog'
'Cat' || 'Dog'; // 'Cat'
'' && 'Dog';    // ''
'' || 'Dog';    // 'Dog'
true && 0;      // 0
null || null;   // null (false 아님)
```

### 풀이 순서

1. 괄호 `( )` 안부터 계산
2. `!`가 붙은 피연산자를 true 또는 false로 변환
3. 마지막으로 `&&`, `||` 반환 규칙 적용

- `!`는 바로 뒤 피연산자에만 적용, 식 전체가 아님
- 마지막에 적용한 연산자가 `!`면 결과는 불리언, `&&` / `||`면 피연산자 중 하나의 원래 값

```js
// a = '', b = 5
!a && b;   // !'' → true, true && 5 → 5
!(a && b); // '' && 5 → '', !'' → true
a || !b;   // !5 → false, '' || false → false
```

### 드 모르간 법칙 (De Morgan, 드 모건)

- 괄호 밖의 `!`를 안으로 넣으면 `&&`와 `||`가 서로 바뀌는 규칙

```
!(a || b)  ===  !a && !b
!(a && b)  ===  !a || !b
```

| a | b | !(a && b) | !a \|\| !b |
|---|---|---|---|
| T | T | F | F |
| T | F | T | T |
| F | T | T | T |
| F | F | T | T |

- 일상어 예시: "카드 또는 계좌이체가 아님" = "카드도 아니고 계좌이체도 아님"
- 부정이 겹친 조건을 읽기 쉽게 바꿀 때 활용

```js
// 읽기 어려움
if (!(isLoggedIn && hasCard)) return;

// 드 모르간 적용
if (!isLoggedIn || !hasCard) return;
```

- 조건 판정 용도로는 완전히 동일
- 값을 반환받아 쓰는 코드에서는 바꾸면 결과 달라짐

```js
const name = a || b;        // a 또는 b의 값
const name2 = !(!a && !b);  // true 또는 false
```

## 7. 그 외 연산자와 규칙

### typeof 연산자

- 타입을 문자열로 반환: `"string"`, `"number"`, `"boolean"`, `"undefined"`, `"symbol"`, `"object"`, `"function"`
- `typeof null`은 `"object"`, 초기 버그를 호환성 때문에 유지
- null 확인은 `=== null`로 별도 처리 필요
- 선언하지 않은 식별자에 사용해도 에러 없이 `"undefined"` 반환

```js
// 흔한 실수: value가 null이면 에러
if (typeof value === 'object') { value.name; }

// 개선
if (value !== null && typeof value === 'object') { value.name; }
```

### 지수 연산자 `**`

- ES7 도입, 이전에는 `Math.pow()` 사용
- 음수를 밑으로 쓸 때 괄호 필요: `(-5) ** 2`
- 이항 연산자 중 우선순위 가장 높음

### 쉼표 연산자 `,`와 그룹 연산자 `( )`

- 쉼표 연산자: 왼쪽부터 평가, 마지막 피연산자 결과 반환
- 그룹 연산자: 우선순위 가장 높음, 먼저 평가할 부분 지정

### 부수 효과가 있는 연산자

- 할당 연산자, 증감 연산자(`++ --`), `delete`
- 나머지 연산자는 원본 값 변경 없음

### 우선순위와 결합 순서

- 우선순위: 여러 연산자 중 먼저 계산할 연산 결정
- 결합 순서: 우선순위가 같을 때 평가 방향 결정
  - 좌항 → 우항: 산술, 비교, `&& || ??`, `.`, `[]`, `()`, `in`, `instanceof`
  - 우항 → 좌항: 할당, 단항(`! typeof delete ++ --`), 삼항, `**`
- 전부 외우기보다 헷갈리면 `( )`로 명시

## 8. 실무 사례

### 금액 input 계산 오류

- 상황: 결제 금액 합산 시 숫자가 이어 붙음
- 원인: `input.value`는 항상 문자열, `+`가 문자열 연결로 동작

```js
const total = input.value + 500;         // '1000' + 500 → '1000500'
const total2 = Number(input.value) + 500; // 1500
```

### includes로 조건 단순화

- 비교할 값이 여러 개면 배열 + `includes`로 논리 연산자 혼용 자체를 제거
- 형태: `목록.includes(찾을 값)`, 주어가 목록

```js
const PAYMENTS = ['card', 'pay', 'bank'];
if (!PAYMENTS.includes(method)) {
  showError('지원하지 않는 결제수단');
}
```
