# 26 함수의 추가 기능

## 26.1 함수의 구분

- ES6 이전의 모든 함수(callable + constructor)
  - 일반 함수로서 호출
  - 생성자 함수로서 호출

| ES6 함수의 구분    | constructor | prototype | super | arguments |
| ------------------ | :---------: | :-------: | :---: | :-------: |
| 일반 함수(Normal)  |      O      |     O     |   X   |     O     |
| 메서드(Method)     |      X      |     X     |   O   |     O     |
| 화살표 함수(Arrow) |      X      |     X     |   X   |     X     |

## 26.2 메서드

- ES6 이전
  - 객체에 바인딩된 함수를 일컫는 의미

- ES6 사양
  - 메서드 축약 표현으로 정의된 함수만을 의미
  - 메서드는 non-constructor(인스턴스 생성할 수 없음)
  - prototype 프로퍼티가 없고 프로토타입도 생성하지 않음
  - 자신을 바인딩한 객체를 가리키는 내부 슬롯 [[HomeObject]]

## 26.3 화살표 함수

### 26.3.1 화살표 함수 정의

- 함수 표현식으로 정의
- 소괄호 (`()`) 안에 매개변수 선언
  - 매개변수 한 개인 경우 소괄호 (`()`) 생략 가능
  - 매개변수가 없는 경우 소괄호 (`()`) 생략할 수 없다.
- 함수 몸체를 하나의 표현식으로 작성하면 중괄호를 생략하고 표현식의 평가 결과를 암묵적으로 반환할 수 있다.
  - 객체 리터럴을 암묵적으로 반환할 때는 `() => ({})`처럼 소괄호로 감싼다.
  - 블록 몸체는 중괄호(`{}`)로 감싸고, 값을 반환하려면 `return`을 명시한다.
- 즉시 실행 함수로 사용 가능
- 일급 객체로 고차 함수에 인수로 전달

### 26.3.2 화살표 함수와 일반 함수의 차이

- 화살표 함수는 인스턴스를 생성할 수 없는 non-constructor
  - prototype 프로퍼티가 없고 프로토타입도 생성하지 않음
- 중복된 매개변수 이름을 선언할 수 없다.
  - 일반 함수는 strict mode에서만 에러 발생
- 함수 자체의 this, arguments, super, new.target 바인딩을 갖지 않음
  - 각 항목을 참조하면 이를 제공하는 상위 스코프의 바인딩을 사용한다.

### 26.3.3 this

- 콜백 함수의 this와 외부 함수의 this가 서로 다른 값을 가리키는 문제
  - this를 할당, map의 두 번째 인수 활용, bind 메서드 사용

- ES6에서는 화살표 함수를 사용하여 "콜백 함수 내부의 this 문제" 해결
  - 화살표 함수로 작성한 콜백은 상위 스코프의 `this`를 사용하므로(lexical this), 외부 메서드의 `this`를 콜백에서도 그대로 사용할 수 있다.
  - call, apply, bind를 사용해서 화살표 함수 내부의 this를 교체할 수 없다.

- 화살표 함수 사용 지양
  - 메서드 정의할 때는 ES6 메서드(축약 표현)를 사용하는 것이 좋다.
    - 화살표 함수 사용할 경우 this가 메서드 호출 객체가 아닌 상위 스코프의 this를 가리키기 때문
    - 프로토타입 객체의 프로퍼티에 화살표 함수 할당할 때도 같은 문제
  - 프로퍼티를 동적 추가할 때는 일반 함수를 할당
    - ES6 메서드를 동적 추가하고 싶다면 객체 리터럴을 바인딩하고 프로토타입의 constructor 프로퍼티와 생성자 함수 간의 연결을 재설정
  - 클래스 필드에 함수 할당하는 경우
    - 클래스 필드에 할당한 화살표 함수는 프로토타입 메서드가 아니라 인스턴스 메서드가 됨

## 26.4 Rest 파라미터

### 26.4.1 기본 문법

- Rest 파라미터는 함수에 전달된 인수들의 목록을 배열로 전달받는다.
  - 먼저 선언된 매개변수의 할당된 인수를 제외한 나머지 인수들로 구성된 배열
  - 반드시 마지막 파라미터이고 단 하나만 선언할 수 있다.
  - 매개변수 개수를 나타내는 함수 객체의 length 프로퍼티에 영향을 주지 않는다.

### 26.4.2 Rest 파라미터와 arguments 객체

- ES5에서는 가변 인자 함수의 경우 arguments 객체를 활용하여 인수를 전달받음.
  - arguments 객체는 호출 시 전달된 인수들의 정보를 담고 있는 순회 가능한 유사 배열 객체
  - 함수 내부에서 지역 변수처럼 사용
  - `Array.prototype.slice.call(arguments)`처럼 배열 메서드를 빌려 `arguments` 객체를 배열로 변환

- ES6에서는 Rest 파라미터를 사용하여 가변 인자 함수의 인수 목록을 배열로 직접 전달

- 함수와 ES6 메서드는 Rest 파라미터와 arguments 객체를 모두 사용할 수 있다.
  - 화살표 함수는 자체의 arguments 객체를 가지 않으므로 가변 인자 함수를 구현해야 할 때는 반드시 Rest 파라미터 사용
