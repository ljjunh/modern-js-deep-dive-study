## 값(value)

- 값이란 식이 평가되어 나온 결과를 뜻한다.
- 모든 값은 데이터 타입을 가진다.
- 같은 메모리에 저장된 2진수의 값이여도 데이터 타입에 따라 해석되는 것은 다르다.
  - ex) 0100 0001의 숫자 데이터 타입은 65 이지만 문자로 해석하면 'A',

## 리터럴(Literal)

- 값을 생성하는 방법은 리터럴이 있다.
- 리터럴은 사람이 이해할 수 있는 문자 또는 약속된 기호를 통해 값을 생성하는 표기법이다.
- 코드에 리터럴 3을 기술하면 자바스크립트 엔진은 숫자 3 값을 생성해 메모리 셸에 할당한다.
- 리터럴로 값이 생성되는 시점은 런타임이다.
  - 단, var 변수의 undefined 초기화는 런타임 이전 소스코드 평가 단계에서 이뤄진다.
- 리터럴의 종류(정수, 부동소수점, 2진수, 8진수, 16진수, 문자열, 불리언, null, undefined, 객체, 배열, 함수, 정규 표현식)

## 표현식 (Expression)

- 표현식은 값으로 평가될 수 있는 모든 문이다.
- 값으로 평가란?
  - 새로운 값을 생성(메모리에 저장)하거나
  - 이미 있는 값을 참조(메모리 셸에서 값을 읽어옴)을 뜻한다.
- 표현식은 리터럴 표현식(1, 'a'), 식별자 표현식(resume, person.name, arr[1]), 연산자 표현식(10+20, sum=10), 함수/메서드 호출 표현식(square())가 있다.
  - 표현식과 표현식이 평가되어 나온 값은 동등한 관계로 "동치"다.
  - 따라서 표현식도 값처럼 사용할 수 있다.

## 문 (Statement)

- 문은 프로그램을 구성하는 기본 단위이자 최소 실행 단위이다. (명령문이라고도 함)
- 프로그래밍이란 문의 집합이며 문을 작성하고 순서에 맞게 나열하는 것이다.
- 문은 토큰으로 이루어져 있다.
  - 토큰은 문법적으로 더이상 나눌 수 없는 코드의 기본 원소를 뜻한다.
  - var | sum | = | 1 | + | 2 | ;
- 문은 선언문, 할당문, 조건문, 반복문 등으로 구성되어있다.

## 표현식인 문 vs 표현식이 아닌 문

- 값이 평가되면 표현식, 동작만 수행되면 문이다.
- 가장 쉬운 판별법은 변수에 담아보면 된다. 변수에 담았을 때 말이 된다면 표현식, 아니라면 문이다.
- ```javascript
  var a = 100;          // 표현식이 아닌 문 (선언문)
  var b = var a = 100;  // SyntaxError → 값처럼 쓸 수 없음

  a = 100;              // 표현식인 문 (할당문)
  var c = a = 100;      // 가능 → a = 100이 100으로 평가됨
  ```

## 세미콜론과 ASI

- 세미콜론은 문의 종결을 뜻한다.
- 국어로 치면 마침표 같은 것으로 엔진에게 알려주는 문의 구분선이다.
- 하지만 문을 묶은 중괄호에는 세미콜론을 붙이지 않는다.
- 세미콜론은 자바스크립트 엔진이 런타임 이전의 파싱 단계에서 ASI(세미콜론 자동 삽입 기능)을 수행해 붙여준다.
  - 하지만 기입하지 않고 엔진에 의존하면 개발자의 의도와 다르게 문이 해석될 수도 있다.
- 완료 값 (Completion Value)
  - 크롬 콘솔은 표현식을 찍어보면 결과로 식의 평과 결과를 나타낸다.
  - 표현식이 아닌 문을 사용하면 항상 undefined(리터럴 undefined 아님, 크롬 콘솔의 결과 없음을 표시하는 것)를 출력하는 것을 완료 값이라고 한다.
  - 완료 값은 표현식의 평가 결과가 아니라 다른 값과 같이 변수에 할당할 수 없고 참조할 수도 없다.
