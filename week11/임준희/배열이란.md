### 배열이란

- 배열은 값을 순서대로 나열한 자료구조. 각 값을 요소, 위치를 인덱스라 하고 인덱스는 0부터 시작
- 자바스크립트에 배열 타입은 없음. typeof [] === 'object' 배열은 Array 생성자로 만들어지는 exotic object

### 자바스크립트 배열은 배열이 아니다

- 자료구조의 배열은 같은 크기의 요소가 메모리에 연속으로 놓임. 주소를 계산해 바로 접근하니 O(1)
- 자바스크립트 배열은 사양상 "인덱스 키를 가진 객체". 요소 크기가 같을 필요도, 연속일 필요도 없음 그래서 희소 배열이 허용됨

### length와 희소 배열

- length는 0이상 2^32 - 1 미만의 정수
- 요소를 넣고 빼면 자동 갱신. 직접 대입도 가능
  - 작은 값을 대입하면 그 이상 인덱스가 실제로 삭제
  - 큰 값을 대입하면 length만 바뀜. 요소가 생기거나 메모리를 잡지 않음
  - 정수가 아니거나 범위 밖이면 RangeError
- 희소배열은 인덱스가 연속으로 채워지지 않은 배열
- 희소 배열은 length와 실제 요소 개수가 다름. [, 2, , 4].length는 4지만 키는 '1', '3' 둘 뿐
- 인덱스가 아닌 키는 요소가 아님. length에 영향 없음

### 배열 생성

| 방법                     | 특징                                                                             |
| ------------------------ | -------------------------------------------------------------------------------- |
| 리터럴 [1, 2]            | 가장 흔함. [1, , 3]은 희소 배열                                                  |
| Array(n) / new Array(n)  | 인수 1개가 Number면 length가 n인 희소 배열. 음수, 소수, 2^32-1 초과면 RangeError |
| Array(a, b) / Array('3') | 인수가 2개 이상이거나 Number가 아니면 그 값들을 요소로                           |
| Array.of(n)              | 인수를 무조건 요소로. Array.of(3) -> [3]                                         |
| Array.from(x, fn)        | 유사 배열 객체나 이터러블을 배열로. 두 번째 인수로 각 요소를 변환                |

- Array는 new 없이 불러도 똑같이 동작

### 참조, 추가, 삭제

- arr[i]는 프로퍼티 접근과 같음. 없는 인덱스는 undefined. 희소 배열의 구멍도 undefined
- 없는 인덱스에 대입하면 요소 추가. length보다 큰 인덱스에 넣으면 희소 배열
- delete arr[1]은 프로퍼티만 지움. length는 그대로라 희소 배열이 됨
- 중간을 깔끔히 빼려면 splice(index, 1)

### 배열 메서드

원본을 바꾸는 메서드(mutator)와 새 배열을 돌려주는 메서드(accessor)를 구분하는 게 이 절의 전부
| 원본 변경 | 반환값 |
| -- | -- |
| push(...items) | 새 length |
| pop() | 뺀 요소 |
| unshift(...items) | 새 length |
| shift() | 뺀 요소 |
| splice(start, deleteCount, ...items) | 제거한 요소들의 배열 |
| reverse() | 원본 자신 |
| fill(value, start, end) | 원본 자신 |
| sort(compareFn) | 원본 자신 |

| 원본 유지         | 반환값                                             |
| ----------------- | -------------------------------------------------- |
| concat(...items)  | 새 배열. 인수가 배열이면 풀어서 붙임               |
| slice(start, end) | 얕은 복사한 새 배열. end 미포함. 음수는 끝에서부터 |
| join(sep)         | 문자열. 기본 구분자 ,                              |
| flat(depth)       | 새 배열. 기본 depth 1                              |
| indexOf(x, from)  | 인덱스                                             |
| includes(x, from) | boolean                                            |
| Array.isArray(x)  | 정적 메서드. 배열이면 true                         |

### 고차 함수

콜백을 받는 메서드들. 전부 콜백에 (요소, 인덱스, 배열 자신) 세 인수를 넘기고, 두 번재 인수 thisArg로 콜백의 this를 지정할 수 있음
| 메서드 | 돌려주는 것 | 빈 배열이면 |
| -- | -- | -- |
|forEach | 항상 undefined | 아무것도 안 함 |
| map | 콜백 반환값들로 만든 새 배열. length 같음 | []|
| filter | 콜백이 truthy인 요소만 모은 새 배열 | [] |
| reduce(fn, init) | 누적값 하나 | init 없으면 TypeError |
|some | 하나라도 truthy면 true | false |
|every | 전부 truthy면 true | true |
| find | 처음 truthy인 요소. 없으면 undefined | undefined |
| findIndex | 처음 truthy인 인덱스. 없으면 -1 | -1 |
|flatMap | map 후 1단계 flat | [] |
