### 일급 객체

1. 무명의 리터럴로 생성할 수 있다(런타임에 생성 가능)
2. 변수나 자료구조(객체, 배열)에 저장할 수 있다
3. 함수의 매개변수에 전달할 수 있다
4. 함수의 반환값으로 사용할 수 있다

- 함수가 일급 객체라는 것은 함수를 값과 똑같이 다룰 수 있다는 뜻이다. 값이 올 수 있는 자리라면 어디든 함수 리터럴을 쓸 수 있고 런타임에 함수 객체로 평가된다. 매개변수로 넘기고 반환값으로 돌려줄 수 있다는 점이 함수형 프로그래밍을 가능하게 한다.
- 함수는 객체지만 일반 객체와 다르다. 호출할 수 있고(`[[Call]]`), 함수 고유의 프로퍼티를 갖는다.

## 함수 객체의 프로퍼티

함수 객체의 own 프로퍼티는 `length`, `name`, `arguments`, `caller`, `prototype`이다. `__proto__`는 own이 아니라 `Object.prototype`에서 상속받은 접근자 프로퍼티다.

### arguments 프로퍼티

- 함수 객체의 `arguments`(foo.arguments) 프로퍼티는 ES3부터 사양에서 빠진 비표준이다. 쓰지 말고, 함수 안에서 지역변수처럼 쓰는 `arguments` 객체를 쓰자.
- `arguments` 객체는 호출 시 전달된 인수 정보를 담은 **순회 가능한 유사 배열 객체**다. 인수를 순서대로 키고 갖고, `length`는 인수 개수, `callee`는 함수 자신. ES6부터 `Symbol.iterator`가 있어 이터러블이기도 하다.
- 자바스크립트는 매개변수와 인수 개수를 확인하지 않으므로, 인수가 부족하면 undefined, 많으면 초과분은 매개변수에는 안 들어가지만 arguments에는 전부 남는다.
- 유사 배열이지 배열이 아니다. 배열 메서드를 쓰려면 `Array.prototype.slice.call(arguments)`로 바꾸거나 `[...arguments]`로 펼쳐야 한다. 이 번거로움을 없앤 것이 ES6의 `Rest` 파라미터다.
- 비엄격 모드의 단순 매개변수 함수에서는 arguments와 매개변수가 연결되어 있다. arguments[0] = 9를 하면 매개변수 a도 9가 된다. 엄격 모드이거나 기본값, 나머지, 구조분해 매개변수가 하나라도 있으면 연결이 끊긴다.(mapped vs unmapped arguments)
- mapped vs unmapped arguments: arguments와 매개변수가 연결됐는지 여부
- mapped arguments: 비엄격 모드이고 매개변수가 단순한 이름뿐일 때. arguments[0]와 매개변수 a가 같은 변수를 공유하고 한쪽을 바꾸면 다른쪽도 바뀐다.
- unmapped arguments: 엄격 모드이거나, 기본값, 나머지, 구조분해 매개변수가 하나라도 있을 때. arguments는 호출 시점의 인수를 복사해 둔 별개의 객체다.

```javaScript
function m1(a) {
    arguments[0] = 9;
    return a;
}
m1(1); // 9 arguments를 바꿨는데 a가 바뀜

function m2(a) {
    'use strict';
    arguments[0] = 9;
    return a;
}
m2(1); // 1 엄격 모드: 안 바뀜

function m3(a, b = 0){ // 기본값 매개변수 있음
    arguments[0] = 9;
    return a;
}
m3(1); // 1 비엄격이어도 안 바뀜
```

### caller 프로퍼티

- 사양에 없는 비표준이고 표준화 계획도 없다. 참고만 하고 쓰지 말자.
- 자신을 호출한 함수를 가리킨다.

### length 프로퍼티

- 함수를 정의할 때 적은 매개변수 개수. 정확히는 호출자가 반드시 넘겨야 하는 인수의 개수다.
- arguments객체의 length(인수 개수)와 함수의 length(매개변수 개수)는 다른 값이다.
- arguments.length = 호출할 때 실제로 넘어온 인수 개수
- 함수의 length = 매개변수 개수(기본값, rest 앞까지)

### name 프로퍼티

- 함수 이름으로 기명 함수 표현식은 그 이름, 익명 함수 표현식은 ES5에서 빈 문자열이었지만 ES6부터는 할당된 변수 이름, 함수 선언문은 선언함 이름이다.
- 함수 이름과 함수를 가리키는 식별자는 다르다. 호출은 식별자로 한다.

### **proto** 접근자 프로퍼티

- 모든 객체는 `[[Prototype]]` 내부 슬롯에 ** 자기 부모(프로토타입) 객체**를 담고 있다. 내부 슬롯에는 직접 접근할 수 없고 `__proto__` 접근자를 통해 간접 접근한다.
- `__proto__`는 각 객체의 own 프로퍼티가 아니라 `Object.prototype`에 있는 접근자 프로퍼티(getter/setter)를 상속받아 쓰는 것이다.
- 프로퍼티를 찾을 때 자기에게 없으면 `[[Prototype]]`을 따라 부모로, 없으면 또 그 부모로 올라간다. 이것이 프로토타입 체인이다.
- 함수의 부모는 Function.prototype이고, 그 부모는 Object.prototype이다. 그래서 함수에서 `call`이나 `hasOwnProperty`도 쓸 수 있다.
- `hasOwnProperty`는 상속받은 프로퍼티에는 false를 돌려준다.

### prototype 프로퍼티

- `__proto__`가 "내 부모"라면, `prototype`은 **"내가 new로 만들 인스턴스에게 부모로 줄 객체"**다. 함수만 갖는 데이터 프로퍼티다.
- 생성자 함수로 호출할 수 있는 함수(constructor)와 제너레이터 함수만 갖는다.
- 함수를 만들면 엔진이 빈 객체를 하나 만들어 `prototype`에 넣어 두고, 그 객체 안에는 자기 함수를 가리키는 `constructor` 하나만 들어 있다.
- `new Person()`은 빈 객체를 만들고 그 객체의 `[[Prototype]]` 슬롯에 `Person.prototype`을 꽃은 뒤, 그 객체를 this로 해서 본문을 실행한다. 그래서 다음이 성립한다.

```javaScript
const p = new Person("kim");
p.__proto__ === Person.prototype // true
```

둘의 관계를 한 눈에

```
Person (함수)
  ├─ prototype ──→ Person.prototype  { constructor: Person, sayHi }
  │                   └─ [[Prototype]] ──→ Object.prototype ──→ null
  └─ [[Prototype]] ──→ Function.prototype ──→ Object.prototype ──→ null

p = new Person("kim")
  ├─ name: "kim"
  └─ [[Prototype]] ──→ Person.prototype   (위의 그 객체)
```
