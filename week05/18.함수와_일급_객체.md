# 18 함수와 일급 객체

## 18.1 일급 객체

- 다음 조건을 만족하는 객체를 **일급 객체**라 한다.
  1. 무명의 리터럴로 생성할 수 있다. 즉, 런타임에 생성이 가능하다.
  2. 변수나 자료구조(객체, 배열 등)에 저장할 수 있다.
  3. 함수의 매개변수에 전달할 수 있다.
  4. 함수의 반환값으로 사용할 수 있다.

- 함수가 일급 객체라는 것은 함수를 객체와 동일하게 사용할 수 있다는 의미
- 함수는 일반 객체와 같이 함수의 매개변수에 전달할 수 있으며, 함수의 반환값으로 사용할 수 있다는 것이다.
  - 함수형 프로그래밍을 가능케 하는 자바스크립트의 장점 중 하나
- 일반 객체와 달리 호출할 수 있다는 점, 함수 고유의 프로퍼티를 소유한다는 차이가 있다.

## 18.2 함수 객체의 프로퍼티

- 함수 객체의 주요 프로퍼티: length, name, prototype(함수 종류에 따라 소유 여부가 다름)
  - arguments, caller는 오래된 기능이므로 사용을 피한다.
- 일반적인 객체는 프로토타입 체인을 통해 Object.prototype의 프로퍼티를 상속받는다. Object.create(null)로 만든 객체처럼 예외도 있다.

### 18.2.1 arguments 프로퍼티

- 함수 객체의 arguments 프로퍼티(함수.arguments)와 함수 내부의 arguments 객체는 구분해야 한다.
  - 함수.arguments는 폐기 예정인 기능이며, strict mode 함수에서 접근하면 TypeError가 발생한다.
- arguments 객체는 함수 호출 시 전달된 인수들의 정보를 담고 있는 순회 가능한 유사 배열 객체
- 일반 함수 내부의 arguments는 지역 바인딩으로 제공된다. 외부에서 직접 참조할 수는 없지만 반환하거나 전달할 수 있다.
  - 화살표 함수는 자체 arguments를 갖지 않으며, 외부 스코프의 arguments를 참조할 수 있다.
- 함수가 호출되면 함수 몸체 내에서 암묵적으로 매개변수가 선언되고 undefined로 초기화된 이후 인수 할당
- arguments 객체는 매개변수 개수를 확정할 수 없는 가변 인자 함수를 구현할 때 유용하다
- arguments 객체가 유사 배열 객체라는 번거로움을 해결하기 위해 ES6에서 Rest 파라미터 도입
  - arguments 객체의 중요성이 이전 같지는 않음.

> 유사 배열 객체란 length 프로퍼티를 가진 객체로 for문으로 순회할 수 있는 객체를 말한다. <br/> 유사 배열 객체에서 배열 메서드를 사용하려면 Function.prototype.call, Function.prototype.apply를 사용해 간접 호출할 수 있다. Array.from(arguments)로 배열로 변환해 사용할 수도 있다.

### 18.2.2 caller 프로퍼티

- 함수 자신을 호출한 함수를 가리킨다.
- ECMAScript 사양에 포함되지 않은 비표준 프로퍼티

### 18.2.3 length 프로퍼티

- 함수 객체의 length 프로퍼티는 함수가 기대하는 매개변수의 개수를 나타낸다.
  - 첫 기본값 매개변수 이전의 매개변수만 세고, Rest 파라미터는 제외한다.
  - 구조 분해 패턴은 내부 변수의 개수와 관계없이 매개변수 하나로 센다.
  - 예: `function f(a, b = 1, ...rest) {}`의 f.length는 1이다.
- arguments 객체와 함수 객체의 length 프로퍼티 값은 다를 수 있음

### 18.2.4 name 프로퍼티

- ES6에서 정식 표준이 되었다.
- 익명 함수 표현식의 경우 ES5에서 name 프로퍼티는 빈 문자열을 값으로 갖지만 ES6에서는 함수 객체를 가리키는 식별자를 값으로 갖는다.

### 18.2.5 \_\_proto\_\_ 접근자 프로퍼티

- 모든 객체는 [[Prototype]] 이라는 내부 슬롯(객체지향 프로그래밍의 상속을 구현하는 프로토타입 객체)을 갖는다.

- `__proto__` 프로퍼티는 [[Prototype]] 내부 슬롯이 가리키는 프로토타입 객체에 접근하기 위해 사용하는 접근자 프로퍼티

### 18.2.6 prototype 프로퍼티

- 일반적인 함수 선언문과 함수 표현식으로 만든 함수는 prototype 프로퍼티를 소유하며 생성자로 호출할 수 있다. 화살표 함수는 prototype 프로퍼티가 없고 생성자로 호출할 수 없다.
  - 다만 prototype 소유 여부만으로 생성자 여부를 판단할 수는 없다.
  - 생성자 함수를 bind한 함수는 자체 prototype 없이도 new로 호출할 수 있다.
  - 제너레이터 함수는 prototype이 있지만 new로 호출할 수 없다.
- prototype 프로퍼티는 함수가 객체를 생성하는 생성자 함수로 호출될 때 생성자 함수가 생성할 인스턴스의 프로토타입 객체를 가리킨다.
