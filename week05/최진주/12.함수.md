# 12장. 함수

## 핵심 요약

- 함수: 입력(매개변수) → 처리 → 출력(반환값)을 하나로 묶은 코드 블록
- 함수는 객체이자 값, 변수 할당·인수 전달·반환 모두 가능 (일급 객체)
- 함수 호출은 함수 이름이 아닌, 함수 객체를 가리키는 식별자로 수행
- 정의 방식에 따라 함수 객체 생성 시점(호이스팅)이 다름
- 객체를 인수로 넘기면 참조가 전달되어 외부 상태 변경 위험 존재

---

## 함수 정의 방식

| 방식 | 형태 | 특징 |
|---|---|---|
| 함수 선언문 | `function add(x, y) {}` | 이름 생략 불가, 값으로 평가되지 않는 문 |
| 함수 표현식 | `const add = function (x, y) {};` | 이름 생략 가능, 값으로 평가 |
| Function 생성자 | `new Function('x', 'y', 'return x + y')` | 클로저 미생성 등 동작 상이, 사용 지양 |
| 화살표 함수 | `const add = (x, y) => x + y;` | 항상 익명, 26장에서 상세 |

- 변수는 "선언", 함수는 "정의"라고 표현

---

## 함수 이름과 식별자

- 함수 이름은 함수 몸체 내부에서만 참조 가능한 식별자
- 기명 함수 표현식의 이름은 외부에서 호출 불가, 재귀 호출 시 내부에서 사용

```js
const add = function sum(a, b) { return a + b; };
add(1, 2); // 3
sum(1, 2); // ReferenceError: sum is not defined
```

- 함수 선언문은 엔진이 함수 이름과 동일한 이름의 식별자를 암묵적으로 생성
- 외부에서 호출되는 것은 함수 이름이 아니라 이 암묵적 식별자

```js
function foo() {}
// 엔진 내부 처리 개념: var foo = function foo() {};
```

- 같은 코드도 값이 와야 하는 위치(할당 우변, 그룹 연산자 내부 등)면 표현식으로 해석

```js
(function bar() {});
bar(); // ReferenceError — 표현식이라 식별자 bar 미생성
```

---

## 호이스팅: 선언문 vs 표현식

| 구분 | 함수 선언문 | 함수 표현식 |
|---|---|---|
| 생성 시점 | 런타임 이전, 함수 객체 생성 후 식별자에 할당 | 할당문 실행 시점 |
| 호이스팅 대상 | 함수 객체 전체 | 변수 선언만 |
| 정의 전 호출 | 가능 | var: TypeError / let·const: ReferenceError |

```js
console.log(typeof foo); // 'function'
console.log(typeof bar); // 'undefined'

function foo() {}
var bar = function () {};
```

- `typeof`는 함수를 호출하지 않고 타입 문자열만 반환
- 정의 전 호출이 가능한 선언문보다 표현식 사용을 권장하는 의견 존재
- 블록(`if`, `for`) 내부 함수 선언문은 엄격 모드 여부에 따라 동작이 달라 사용 지양

## 매개변수와 인수

- 매개변수: 정의 시 선언하는 변수 / 인수: 호출 시 전달하는 값
- 매개변수는 호출 시 함수 내부에 생성, undefined로 초기화 후 인수 할당
- 매개변수 유효 범위는 함수 몸체 내부
- 인수의 개수·타입 검사 없음
- 부족한 인수는 undefined, 초과 인수는 무시 (arguments 객체에는 보관)

```js
function total(price, fee) { return price + fee; }

total(1000);        // NaN — 1000 + undefined
total(1000, null);  // 1000 — 산술 연산에서 null은 0
total(1000, '500'); // '1000500' — 문자열이 있으면 연결
```

### 기본값 처리 비교

| 방식 | 0 전달 | null 전달 | undefined 전달 |
|---|---|---|---|
| `fee = 3000` (매개변수 기본값) | 0 | null | 3000 |
| `fee \|\| 3000` | 3000 | 3000 | 3000 |
| `fee ?? 3000` | 0 | 3000 | 3000 |

- 매개변수 기본값은 undefined일 때만 적용
- `||`는 0, 빈 문자열도 falsy로 판단해 기본값으로 대체
- 무료배송(0원)처럼 0이 유효한 값이면 `||` 사용 시 오류 발생
- `??`(ES2020)는 null과 undefined만 대체

### 매개변수 개수

- 문법상 제한은 사실상 없음, 적을수록 좋음 (이상적으로 0개, 많아도 3개 이내 권장)
- 많아지면 객체 하나로 묶어 전달, 순서 의존 제거

```js
createOrder({ name: '상품A', qty: 2, price: 10000 });
```

## 반환문

- `return`: 값 반환 후 함수 실행 즉시 종료
- `return` 생략 또는 값 없이 사용 시 undefined 반환
- `return`과 값 사이에 줄바꿈 시 자동 세미콜론 삽입(ASI)으로 `return;` 처리

```js
function getUser() {
  return
  { name: 'Lee' };
}
getUser(); // undefined
```

- 함수 몸체 외부에서 `return` 사용 시 문법 에러
- 화살표 함수는 중괄호가 없을 때만 암묵적 반환, 중괄호 사용 시 `return` 필요

```js
const a = (n) => n * 2;          // a(2) → 4
const b = (n) => { n * 2; };     // b(2) → undefined
const c = (n) => { return n * 2; }; // c(2) → 4
```

## 참조에 의한 전달과 외부 상태 변경

- 원시값 인수: 값 자체가 복사되어 원본 유지
- 객체 인수: 참조(주소)가 복사되어 프로퍼티 변경 시 원본도 변경
- 매개변수와 외부 변수는 이름이 같아도 별개 변수
- 매개변수 재할당은 객체여도 외부에 영향 없음

```js
function update(price, item) {
  price = 0;
  item.price = 0;
}

let price = 1000;
const item = { price: 1000 };
update(price, item);
console.log(price, item.price); // 1000 0
```

```js
function reset(item) { item = { price: 0 }; } // 재할당 → 외부 영향 없음
function clear(item) { item.price = 0; }      // 공유 객체 변경 → 외부도 변경
```

- 여러 곳에서 공유하는 객체가 변경되면 변경 시점·주체 추적 어려움
- 해결: 원본을 수정하지 않고 새 객체 생성 (불변성 유지)
- React는 state 변경 여부를 참조 비교로 판단, 원본 직접 수정 시 재렌더링 누락 가능

## 즉시 실행 함수 (IIFE)

- 정의와 동시에 한 번만 실행, 재호출 불가
- 그룹 연산자로 감싸 표현식으로 평가한 뒤 호출

```js
(function () { console.log('run'); }()); // 'run'
(function () { console.log('run'); })(); // 'run'
```

```js
function () {}();    // SyntaxError — 선언문으로 해석되는데 이름 없음
function foo() {}(); // SyntaxError — 선언문 뒤 ASI 후 빈 그룹 연산자만 남음
```

- 용도: 변수를 함수 내부에 격리해 전역 이름 충돌 방지
- 현재는 모듈(`import`/`export`)이 같은 역할 대체

## 재귀 함수와 중첩 함수

- 재귀 함수: 자기 자신을 호출, 탈출 조건 필수
- 탈출 조건 누락 시 무한 호출로 스택 오버플로 발생

```js
function factorial(n) {
  if (n <= 1) return 1;
  return n * factorial(n - 1);
}
factorial(5); // 120
```

- 반복문으로 대체 가능하면 반복문이 안전한 경우 많음, 트리 탐색처럼 재귀가 직관적일 때 사용
- 중첩 함수: 함수 내부에 정의한 헬퍼 함수, 외부 함수의 변수 참조 가능
- 13장 스코프, 24장 클로저로 연결

## 콜백 함수와 고차 함수

| 구분 | 의미 | 예 |
|---|---|---|
| 고차 함수 | 함수를 인수로 받거나 함수를 반환하는 함수 | `map`, `filter`, `addEventListener`, `setTimeout` |
| 콜백 함수 | 다른 함수에 인수로 전달되는 함수 | `map`에 넘기는 함수, 이벤트 핸들러 |

- `A(B)` 형태에서 받는 쪽 A가 고차 함수, 넘겨지는 B가 콜백
- 공통 흐름은 고차 함수가, 매번 달라지는 처리는 콜백이 담당

```js
const prices = [1000, 2000];
const format = (n) => `${n}원`;

prices.map(format); // ['1000원', '2000원']
// 고차 함수: map / 콜백 함수: format
```

- 콜백은 괄호 없이 함수 자체를 전달
- `prices.map(format())`은 format이 즉시 호출되어 반환값(함수 아님)이 전달됨 → TypeError
- 익명 콜백은 고차 함수 호출마다 새로 생성, 재사용할 콜백은 외부에 정의

## 순수 함수와 부수 효과

| 구분 | 순수 함수 | 비순수 함수 |
|---|---|---|
| 외부 상태 의존 | 없음 | 있음 |
| 외부 상태 변경 | 없음 | 있음 (부수 효과) |
| 같은 입력의 결과 | 항상 동일 | 달라질 수 있음 |

- 부수 효과 예: 외부 변수 변경, 원본 배열·객체 변경, 콘솔 출력, 네트워크 요청, DOM 조작
- `Date.now()`, `Math.random()`처럼 호출마다 결과가 달라지는 함수도 비순수
- 순수 함수는 필요한 데이터를 모두 매개변수로 받고, 결과를 새 값으로 반환
- 순수 함수 중심 설계는 예측·테스트 용이, 함수형 프로그래밍의 기반

### 원본을 변경하는 배열 메서드

| 원본 변경 | 원본 유지 대안 |
|---|---|
| `arr.sort()` | `arr.toSorted()` (ES2023), `[...arr].sort()` |
| `arr.reverse()` | `arr.toReversed()` (ES2023), `[...arr].reverse()` |
| `arr.push(x)` | `[...arr, x]` |

- `map`, `filter`는 원본을 변경하지 않고 새 배열 반환
- 숫자 정렬 시 비교 함수 필수, 생략 시 문자열 기준 정렬

```js
[10, 9, 1].sort();                // [1, 10, 9]
[10, 9, 1].sort((a, b) => a - b); // [1, 9, 10]
```
