# 13장. 스코프

## 핵심 요약

- 스코프: 식별자가 유효한 범위, 식별자를 찾는 규칙
- 식별자 결정: 같은 이름이 여러 개일 때 참조할 대상을 정하는 과정
- 스코프 체인: 현재 스코프에서 상위 스코프 방향으로만 탐색
- 렉시컬 스코프: 상위 스코프는 호출 위치가 아닌 정의 위치로 결정
- `var`는 함수 레벨, `let`/`const`는 블록 레벨 스코프

---

## 전역 스코프와 지역 스코프

| 구분 | 선언 위치 | 참조 가능 범위 |
| --- | --- | --- |
| 전역 | 코드 최상위 | 코드 어디서든 |
| 지역 | 함수 내부 | 해당 함수와 그 하위 함수 |

- 섀도잉: 하위 스코프에 같은 이름 선언 시 상위 변수가 가려짐

```js
var x = 'global';

function foo() {
  var x = 'local';
  console.log(x); // local
}

foo();
console.log(x); // global
```

---

## 스코프 체인

- 스코프는 중첩 구조로 연결된 계층
- 탐색 순서: 현재 스코프 → 상위 스코프 → 전역 스코프
- 하위 스코프 방향 탐색 없음
  - 각 스코프는 상위 스코프 참조 하나만 보유
  - 하위 스코프는 여러 개일 수 있고 함수 실행 시에만 생성
- 전역까지 탐색해도 없으면 ReferenceError 발생

| 상황 | 결과 |
| --- | --- |
| 선언 O, 값 할당 X | `undefined` |
| 선언 X | `ReferenceError` |

```js
let a;
console.log(a); // undefined
console.log(b); // ReferenceError: b is not defined
```

---

## 함수 레벨 스코프와 블록 레벨 스코프

| 키워드 | 스코프 단위 | if/for 블록 밖에서 참조 |
| --- | --- | --- |
| `var` | 함수 | 가능 (블록 무시) |
| `let`, `const` | 블록 | 불가 (ReferenceError) |

```js
if (true) {
  var v = 1;
  let l = 2;
}
console.log(v); // 1
console.log(l); // ReferenceError: l is not defined
```

- 반복문에서 차이가 두드러짐

```js
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i));
}
// 3, 3, 3  (모든 콜백이 같은 i 공유)

for (let j = 0; j < 3; j++) {
  setTimeout(() => console.log(j));
}
// 0, 1, 2  (반복마다 새 블록 스코프 생성)
```

## 렉시컬 스코프

| 구분 | 상위 스코프 결정 기준 | JS 채택 |
| --- | --- | --- |
| 렉시컬(정적) 스코프 | 함수 정의 위치 | O |
| 동적 스코프 | 함수 호출 위치 | X |

```js
var x = 1;

function foo() {
  var x = 10;
  bar();
}

function bar() {
  console.log(x);
}

foo(); // 1
bar(); // 1
```

- `bar`의 정의 위치가 전역이므로 상위 스코프는 전역
- `foo` 내부에서 호출해도 `foo`의 지역 변수 `x` 참조 불가

## 클로저와의 연결 (24장)

- 함수는 생성 시 자신이 정의된 환경에 대한 참조 보유
- 외부 함수 실행 종료 후에도 내부 함수가 그 환경의 변수 참조 가능 → 클로저
- 스코프 체인 탐색 자체는 클로저가 아닌 식별자 결정 과정

```js
function makeCounter() {
  let count = 0;
  return function () {
    count++;
    return count;
  };
}

const counter = makeCounter();
console.log(counter()); // 1
console.log(counter()); // 2
```

실행 흐름

1. `makeCounter()` 호출 → 새 환경에 `count = 0` 생성
2. 익명 함수 생성, 정의된 환경(`makeCounter` 내부) 참조
3. 익명 함수 자체를 반환 → `counter`에 할당, `makeCounter` 실행 종료
4. `counter()` 호출 → 함수 내부에 `count` 없음 → 상위 스코프에서 탐색
5. 같은 환경의 `count`를 계속 참조하므로 값 누적

- 호출마다 새 환경 생성 → 클로저끼리 독립

```js
const a = makeCounter();
const b = makeCounter();
console.log(a()); // 1
console.log(a()); // 2
console.log(b()); // 1
```

- 환경 유지 조건: 해당 환경을 참조하는 함수가 살아 있을 것
  - 변수에 할당된 함수: 환경 유지
  - 참조가 사라진 함수: 환경까지 가비지 컬렉션 대상
