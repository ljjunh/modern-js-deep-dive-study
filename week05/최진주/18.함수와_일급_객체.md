# 18장. 함수와 일급 객체

- 함수는 호출 가능한 객체이며, 값처럼 다룰 수 있는 일급 객체
- 일급 객체 성질 덕분에 콜백, 고차 함수, 클로저 패턴 가능
- 함수 객체는 일반 객체에 없는 고유 프로퍼티 보유 (`arguments`, `caller`, `length`, `name`, `prototype`)

---

## 일급 객체

- 일급(first-class): 다른 값과 차별 없이 취급된다는 의미
- 불변성과는 무관, 함수도 객체이므로 프로퍼티 추가·변경 가능
- 자바스크립트는 일반 객체뿐 아니라 함수까지 일급 객체로 취급
- 언어에 따라 함수를 값으로 다룰 수 없는 경우도 있음

| 조건 | 예시 |
|---|---|
| 런타임에 무명 리터럴로 생성 가능 | `const f = function () {}` |
| 변수나 자료구조에 저장 가능 | `const handlers = { pay: f }` |
| 함수의 인수로 전달 가능 | `button.addEventListener('click', f)` |
| 함수의 반환값으로 사용 가능 | `return function () {}` |

- 기억법: 만들고 → 담고 → 넘기고 → 돌려받고
- 일반 객체와의 차이: 호출 가능 여부, 고유 프로퍼티 보유 여부

---

## 고차 함수

- 함수를 인수로 받거나 함수를 반환하는 함수
- 일급 객체 조건 중 인수 전달과 반환값 사용을 함께 활용

```js
function withLog(fn) {
  return function (...args) {
    console.log('호출:', fn.name);
    return fn(...args);
  };
}

function pay(amount, method) {
  return `${amount}원 ${method} 결제`;
}

const loggedPay = withLog(pay);
loggedPay(5000, '카드'); // 호출: pay → '5000원 카드 결제'
```

실행 순서

1. `withLog(pay)`: `pay`를 실행하지 않고 함수 자체를 `fn`으로 전달
2. `withLog`는 내부 함수를 생성해 반환만 함, 내부 함수는 아직 미실행
3. `loggedPay`에 내부 함수 저장
4. `loggedPay(5000, '카드')` 호출 시점에 내부 함수 실행, `args`는 `[5000, '카드']`
5. `fn.name` 출력 후 `pay(5000, '카드')` 실행 결과 반환

- `withLog` 종료 후에도 내부 함수가 `fn`을 참조할 수 있는 이유는 클로저 (24장)
- 원본 `pay`는 변경 없이 기능만 덧붙인 새 함수 생성

## Rest 파라미터와 Spread

| 위치 | 이름 | 역할 |
|---|---|---|
| 함수 정의의 매개변수 `function f(...args)` | Rest 파라미터 | 남은 인수를 배열로 모음 |
| 함수 호출 등 `f(...arr)` | Spread 문법 | 배열을 개별 값으로 펼침 |

- Rest 파라미터는 마지막 매개변수에만 사용 가능
- Rest 파라미터로 모은 값은 진짜 배열

```js
function order(user, ...items) {
  return items;
}
order('진주', '커피', '케이크'); // ['커피', '케이크']
```

```js
const args = [5000, '카드'];

pay(args);    // pay([5000, '카드'], undefined) → 배열이 첫 인수로 통째로 전달
pay(...args); // pay(5000, '카드')
```

## arguments 객체

- 함수에 전달된 인수를 담는 유사 배열 객체 (`length`, 인덱스 보유, 배열은 아님)
- 함수 내부에서 지역 변수처럼 사용, `함수명.arguments` 방식은 표준에서 폐지
- ES6부터 이터러블이므로 `for...of`, Spread 사용 가능

| | `arguments` | Rest 파라미터 |
|---|---|---|
| 타입 | 유사 배열 객체 | 배열 |
| 배열 메서드 | 직접 사용 불가 | 사용 가능 |
| 화살표 함수 | 자체 `arguments` 없음 | 사용 가능 |
| 가독성 | 함수 선언부로 인수 파악 불가 | 선언부에 드러남 |

```js
function sum() {
  return arguments.reduce((a, b) => a + b, 0);
}
sum(1, 2, 3); // TypeError: arguments.reduce is not a function

function sum2(...nums) {
  return nums.reduce((a, b) => a + b, 0);
}
sum2(1, 2, 3); // 6
```

- 가변 인자 함수는 Rest 파라미터로 구현

## length, name, caller

### length

| | 의미 |
|---|---|
| `함수.length` | 함수 정의 시 선언한 매개변수 개수 |
| `arguments.length` | 호출 시 실제로 전달된 인수 개수 |

```js
function f(a, b, c) { return arguments.length; }
f.length; // 3
f(1);     // 1

function g(a, ...rest) {}
g.length; // 1 (Rest 파라미터는 제외)
```

### name

- 함수 이름을 나타내는 프로퍼티, ES6에서 표준화
- 익명 함수 표현식은 ES6부터 할당된 변수 이름을 값으로 가짐
- 함수 이름과 함수를 참조하는 식별자는 별개

```js
const anon = function () {};
anon.name; // 'anon'

const fn = function pay() {};
fn.name; // 'pay'
pay();   // ReferenceError: pay is not defined
```

- 기명 함수 표현식의 이름은 함수 몸체 내부에서만 참조 가능, 외부 호출은 식별자 `fn`으로만 가능
- 에러 스택, 디버깅 시 함수 식별에 활용

### caller

- 자신을 호출한 함수를 가리키는 비표준 프로퍼티, 실무 사용 없음

## 생성자 함수와 prototype

### 생성자 함수

- `new`와 함께 호출해 같은 구조의 객체(인스턴스)를 생성하는 함수
- `new` 호출 시 동작: 빈 객체 생성 → `this`를 그 객체에 연결 → 객체 반환
- 이름 첫 글자를 대문자로 쓰는 것이 관례

| 구분 | 해당 함수 |
|---|---|
| constructor (`new` 호출 가능) | 함수 선언문, 함수 표현식, 클래스 |
| non-constructor (`new` 호출 불가) | 화살표 함수, 메서드 축약 표현 |

### prototype과 `__proto__`

| | `__proto__` | `prototype` |
|---|---|---|
| 소유 | 모든 객체 (`Object.prototype`에서 상속) | constructor 함수만 |
| 의미 | 자신의 프로토타입(부모 객체)을 가리킴 | 생성할 인스턴스의 프로토타입이 될 객체 |
| 관점 | 인스턴스 쪽에서 부모를 봄 | 생성자 함수 쪽에서 자식의 부모를 지정 |

```js
function Card(name) {
  this.name = name;
}

Card.prototype.pay = function () {
  return `${this.name} 결제`;
};

const a = new Card('신한');
const b = new Card('국민');

a.pay();                                // '신한 결제'
a.hasOwnProperty('pay');                // false → 인스턴스 자신에겐 없음
a.pay === b.pay;                        // true → 하나의 함수를 공유
Object.getPrototypeOf(a) === Card.prototype; // true
```

- 프로퍼티를 찾을 때 자신에게 없으면 프로토타입에서 탐색
- 메서드를 `this`에 정의하면 인스턴스마다 함수가 복제됨, `prototype`에 두면 하나를 공유
- non-constructor는 인스턴스를 생성하지 않으므로 `prototype` 프로퍼티 없음

```js
(function () {}).hasOwnProperty('prototype'); // true
(() => {}).hasOwnProperty('prototype');       // false
({ foo() {} }).foo.hasOwnProperty('prototype'); // false
```

- `__proto__` 직접 사용 대신 `Object.getPrototypeOf()` 사용 권장
- `class` 문법도 내부적으로 같은 프로토타입 구조로 동작 (상세 내용은 19장)
