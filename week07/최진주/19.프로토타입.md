# 19장. 프로토타입

- 자바스크립트는 클래스가 아닌 프로토타입 기반으로 상속 구현
- 모든 객체는 부모 역할의 객체(프로토타입)를 참조하고, 없는 프로퍼티는 부모에게서 빌려 씀
- ES6 클래스도 내부적으로는 프로토타입 구조 위에서 동작

---

## 프로토타입이 필요한 이유

- 생성자 함수 안에서 `this`에 메서드 정의 시 인스턴스마다 같은 함수가 새로 생성됨
- 메서드를 `prototype`에 두면 모든 인스턴스가 하나를 공유
- 원칙: 인스턴스별 상태는 `this`, 공통 동작은 `prototype`

```js
// 인스턴스마다 메서드 생성
function Circle(r) {
  this.r = r;
  this.getArea = function () { return Math.PI * this.r ** 2; };
}
new Circle(1).getArea === new Circle(2).getArea; // false

// 프로토타입에 두고 공유
function Circle2(r) { this.r = r; }
Circle2.prototype.getArea = function () { return Math.PI * this.r ** 2; };
new Circle2(1).getArea === new Circle2(2).getArea; // true
```

---

## 관련 용어 구분

| 이름 | 소유 주체 | 역할 |
|---|---|---|
| `[[Prototype]]` | 모든 객체 | 부모 객체를 가리키는 내부 슬롯, 직접 접근 불가 |
| `__proto__` | 모든 객체 (`Object.prototype`에서 상속) | `[[Prototype]]`에 접근하는 getter/setter |
| `prototype` | 생성자가 될 수 있는 함수 | 이 함수로 만들 인스턴스의 부모 지정 |
| `constructor` | 프로토타입 객체 | 자신과 연결된 생성자 함수를 가리킴 |

- 화살표 함수, 메서드 축약 표현은 생성자가 될 수 없어 `prototype` 없음
- `__proto__` 직접 사용 대신 `Object.getPrototypeOf` / `Object.setPrototypeOf` 권장
  - `Object.create(null)`로 만든 객체는 `__proto__` 자체가 없음

---

## 생성자 · 프로토타입 · 인스턴스 관계

```
Person ──prototype──> Person.prototype
   ^                        │
   └──────constructor───────┘
                            ^
me ────[[Prototype]]────────┘
```

```js
function Person(name) { this.name = name; }
const me = new Person('Lee');

Object.getPrototypeOf(me) === Person.prototype; // true
Person.prototype.constructor === Person;        // true
me.constructor === Person;                      // true (체인을 통해 찾음)
```

| 생성 방식 | 결정되는 프로토타입 |
|---|---|
| 객체 리터럴 `{}` | `Object.prototype` |
| `new Person()` | `Person.prototype` |
| `Object.create(proto)` | 인수로 전달한 `proto` |

- 리터럴 객체의 `constructor`가 `Object`인 것은 체인을 따라 찾은 결과일 뿐, `Object` 생성자 호출이 아님
- 프로토타입 객체는 생성자 함수가 만들어지는 시점에 함께 생성

---

## 프로토타입 체인

- 프로퍼티 접근 시 자신 → 프로토타입 → 그 상위 순으로 검색
- 종점은 `Object.prototype`, 그 `[[Prototype]]`은 `null`
- 끝까지 없으면 `undefined` 반환 (에러 아님)

```js
me.hasOwnProperty('name'); // true
// me → Person.prototype → Object.prototype 에서 hasOwnProperty 발견
```

| 구분 | 스코프 체인 | 프로토타입 체인 |
|---|---|---|
| 검색 대상 | 식별자(변수) | 프로퍼티, 메서드 |
| 연결 기준 | 코드가 작성된 위치 | 객체의 `[[Prototype]]` |

- `me.hasOwnProperty` 실행 시 두 체인이 함께 동작
  - 스코프 체인으로 `me` 검색, 프로토타입 체인으로 `hasOwnProperty` 검색

## 섀도잉

- 인스턴스에 프로토타입과 같은 이름의 프로퍼티 추가 시 프로토타입 쪽이 가려짐
- 인스턴스를 통해 프로토타입 프로퍼티 읽기는 가능, 변경·삭제는 불가
  - 대입하면 인스턴스에 새 프로퍼티가 생길 뿐임

```js
Person.prototype.sayHello = function () { return `Hi ${this.name}`; };
me.sayHello = function () { return `Hey ${this.name}`; };

me.sayHello();      // 'Hey Lee'
delete me.sayHello; // 인스턴스 메서드 삭제
me.sayHello();      // 'Hi Lee'
delete me.sayHello; // 프로토타입 메서드는 삭제되지 않음
me.sayHello();      // 'Hi Lee'
```

## 프로토타입 교체와 instanceof

- `prototype`을 객체 리터럴로 통째로 교체하면 `constructor` 연결이 끊김
- 상속 구조가 필요하면 교체보다 클래스 사용이 적합

```js
function User(name) { this.name = name; }
User.prototype = { greet() { return 'Hi'; } };

const u = new User('Kim');
u.constructor === User;   // false
u.constructor === Object; // true
```

- `obj instanceof C`: `C.prototype`이 `obj`의 프로토타입 체인 위에 있는지 검사
  - 생성자 함수 자체가 아닌 `prototype` 객체 기준
  - 프로토타입을 바꾸면 결과도 달라질 수 있음

---

## 직접 상속과 정적 메서드

- `Object.create(proto)`로 생성자 없이 프로토타입 지정 가능

```js
const base = { currency: 'KRW' };
const item = Object.create(base);
item.price = 1000;
item.currency; // 'KRW'
```

- 정적 메서드: 생성자 함수 자체에 붙은 메서드, 인스턴스 체인에 없어 인스턴스로 호출 불가

| 구분 | 예시 | 호출 방식 |
|---|---|---|
| 정적 메서드 | `Object.keys`, `Object.hasOwn` | 생성자로 호출 |
| 프로토타입 메서드 | `Object.prototype.hasOwnProperty` | 인스턴스로 호출 |

## 프로퍼티 존재 확인과 열거

| 방법 | 상속 프로퍼티 포함 | 비고 |
|---|---|---|
| `key in obj` | 포함 | 체인 전체 확인 |
| `Object.hasOwn(obj, key)` | 미포함 | ES2022, 권장 |
| `for...in` | 포함 | 열거 가능한 것만, 심벌 키 제외 |
| `Object.keys / values / entries` | 미포함 | 자신의 열거 가능한 프로퍼티만 |

```js
const product = { name: '아메리카노', price: 4500 };
'toString' in product;              // true
Object.hasOwn(product, 'toString'); // false

for (const k in item) console.log(k); // 'price', 'currency'
Object.keys(item);                     // ['price']
```
