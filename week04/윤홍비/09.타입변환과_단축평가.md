### 타입 변환

- 개발자가 의도적으로 타입을 변환하는 것
  - 명시적 타입 변환 or 타입 캐스팅(type casting)
- 개발자의 의도와는 상관없이 표현식 평가과정에서 타입이 변경되는 것
  - 암묵적 타입 변환 or 타입 강제 변환(type coercion)
- 타입 변환이 기존의 원시값을 재할당해 변경하는 것이 아니라 기존 원시 값을 사용해 다른 타입의 새로운 원시 값을 반환한다.
  - 새로운 타입 값은 단 한번 사용하고 버린다.

### 암묵적 타입 변환

- 표현식 평가 시 코드의 문맥에 부합하지 않다면 에러를 발생시킬 수도 있지만 자바스크립트는 암묵적 타입 변환을 통해 최대한 에러를 발생시키지 않도록 한다.
- 문자열 타입 변환
  - +연산자의 문자열 연결 연산자 : 피연산자 중 하나 이상의 문자열이면 +는 문자열 연결연산자로 동작한다.
    - `1 + '2' = "12"`
  - ES6 템플릿 리터럴 표현식 삽입 : 템플릿 리터럴 내 표현식 평가 결과는 문자열 타입으로 암묵적 타입 변환한다.
    - ``1+1 = ${1 + 1}` // "1+1=2"`
- 숫자 타입으로 변환
  - 산술연산자(-, \*, /)는 숫자값을 만들어야하기 때문에 피연산자를 모두 숫자타입으로 변환한다.
    - 만약 숫자타입으로 변환할 수 없다면 NaN 평가 결과를 리턴한다.
  - 비교 연산자는 피연산자의 크기를 비교하기에 피연산자를 모두 숫자타입으로 변환한다.
  - 참고) +단항 연산자는 숫자타입 값이 아닌 피연산자를 숫자타입으로 암묵적 타입 변환을 수행한다.
  - 빈 문자열, 빈배열, null, false는 0, true는 1로 변환된다.
  - 객체 빈 배열이 아닌 배열, undefined는 NaN이 된다.
- 불리언 타입으로 변환
  - if, for, 삼항조건연산자의 조건식은 논리적 참/거짓으로 평가되어야 하기 때문에 불리언타입으로 암묵적 타입 변환한다.
  - 자바스크립트 엔진은 불리언 타입이 아닌 값을 Truthy, Falsy로 구분한다.
  - 조건식과 같은 문맥에서는 Truthy는 true로, Falsy 값은 false로 암묵적 타입 변환한다.
    - Falsy 값 : false, undefined, null, 0,-0, NaN, ''
    - 이를 제외한 값은 모두 Truthy 값이다.

### 명시적 타입 변환

- 표준 빌트인 생성자 함수(String, Number, Boolean)을 new 연산자 없이 호출
- 빌트인 메서드 사용
- 암묵적 타입 변환 이용
- 문자열 타입으로 변환
  - String 생성자 함수를 new 연산자 없이 호출 : `String(1)`
  - Object.prototype.toString 메서드 사용 : `(1).toString()`
  - 문자열 연결 연산자를 이용 : `1 + ''`
- 숫자 타입으로 변환
  - Number 생성자 함수를 new 연산자 없이 호출 : `Number('0')`
  - parseInt, parseFloat 함수를 사용하는 방법 : `parseInt('0')`, `parseFloat('10.53')`
  - +연산자 사용 : `+'0'`
  - *산술연산자 사용 : `'0'*1`
- 불리언 타입으로 변환
  - Boolean 생성자 함수를 new 연산자 없이 호출 : `Boolean('x')`
  - !부정논리 연산자를 두번 사용 : `!!'x'`

### 단축 평가

#### 논리연산자

- 논리합(||), 논리곱(&&) 연산자는 불리언 값을 반환하는게 아닌 언제나 2개의 피연산자 중 어느 한쪽으로 평가된다.
  - `'Cat' && 'Dog'`
    - 논리곱 연산자는 두개의 피연산자가 true일때 true로 평가되고 좌항에서 우항으로 계산되기 때문에
    - 두번째 연산자가 논리 연산의 결과를 결정해 문자열 'Dog'를 그대로 반환한다.
  - `'Cat' || 'Dog'`
    - 논리합 연산자는 두개의 피연산자중 하나만 true여도 true이다 좌항에서 우항으로 계산되기 때문에
    - 첫번재 연산자가 논리 연산의 결과를 결정해 문자열 'Cat'을 그대로 반환한다.
- 논리합(||), 논리곱(&&) 연산자는 논리연산의 결과를 결정하는 피연산자를 타입변환하지 않고 그대로 반환한다.
- 이를 단축평가 라고 한다.
  - 표현식을 평가하는 도중에 평가 결과가 확정된 경우 나머지 평가를 생략하는 것을 뜻한다.
- 이를 통해 if문을 대신할 수 있다.
  - 조건이 truthy값일때 논리곱 연산자를 활용한다.
    - `message = done && '완료'`
  - 조건이 Falsy값일때 논리곱 연산자를 활용한다.
    - `message = done || 미완료`

- 실제 활용 사례
  - 객체를 가리키기를 기대하는 변수가 null 또는 undefined가 아닌지 확인하고 프로퍼티를 참조할때
    - ```javascript
      var value = elem.value; // TypeError: Cannot read property 'value' of null
      var value = elem && elem.value; // null
      ```
  - 함수 매개변수에 기본값을 설정할때
    - ```javascript
      function getStringLength(str) {
        str = str || "";
        return str.length;
      }

      function getStringLength(str = "") {
        return str.length;
      }
      ```

#### 옵셔널 체이닝 연산자

- ES11(ECMAScript2020)에서 도입된 옵셔널 체이닝(optional chaining) 연산자 `?.`
- 좌항의 연산자가 null or undefined면 undefined 반환, 그렇지 않으면 우항의 프로퍼티 참조를 이어나간다.
  - ```javascript
    var elem = null;
    var value = elem?.value; // undefined
    ```

- 논리곱(&&) 연산자와의 차이점

|                    | 논리곱(`&&`)                                                         | 옵셔널 체이닝(`?.`)   |
| ------------------ | -------------------------------------------------------------------- | --------------------- |
| 평가를 멈추는 기준 | Falsy 값 전체 (`false`, `undefined`, `null`, `0`, `-0`, `NaN`, `''`) | `null`, `undefined`만 |
| 반환값             | 좌항 피연산자를 그대로 반환                                          | `undefined`를 반환    |

- `&&`는 Falsy라는 이유만으로 멈추기 때문에, 프로퍼티 접근이 가능한 `0`이나 `''`에서도 평가를 중단한다.
  - `''`은 프로퍼티에 접근하는 순간 String 래퍼 객체로 감싸지므로 `''.length`는 에러 없이 `0`을 반환한다.
  - 그런데 `&&`는 `''`을 Falsy로 보고 멈춰버려서 의도하지 않은 결과를 만든다.
  - ```javascript
    var str = "";

    var length = str && str.length; // '' (length를 얻지 못한다)
    var length = str?.length; // 0
    ```

- 즉 `&&`는 "Falsy면 멈춤", `?.`는 "값이 없으면(null/undefined) 멈춤"이다.
  - 변수가 null 또는 undefined가 아닌지만 확인하고 프로퍼티를 참조하려는 의도라면 `?.`가 적합하다.

#### null 병합 연산자

- ES11(ECMAScript2020)에서 도입된 null 병합(nullish coalescing) 연산자 `??`
- 좌항의 피연산자가 null or undefined면 우항의 피연산자를 반환, 아니라면 좌항의 피연산자를 반환한다.
- 변수의 기본값 설정에 사용
  - ```javascript
    var foo = null ?? "default string"; // "default string"
    ```

- 논리합(||) 연산자와의 차이점

|                      | 논리합(`\|\|`)                                                         | null 병합(`??`)                                    |
| -------------------- | ---------------------------------------------------------------------- | -------------------------------------------------- |
| 우항을 반환하는 기준 | 좌항이 Falsy 값 (`false`, `undefined`, `null`, `0`, `-0`, `NaN`, `''`) | 좌항이 `null`, `undefined`일 때만                  |
| 좌항을 반환하는 경우 | 좌항이 Truthy 값일 때                                                  | 좌항이 nullish가 아닐 때 (`0`, `''`, `false` 포함) |

- `||`는 좌항이 Falsy면 우항을 반환하기 때문에, `0`이나 `''`처럼 **유효한 값**도 기본값으로 덮어써버린다.
  - 사용자가 의도적으로 입력한 `0`이나 `''`이 기본값으로 바뀌면 예기치 않은 동작이 발생할 수 있다.
  - ```javascript
    var foo = "" || "default string"; // "default string" (''이 덮어써진다)
    var foo = "" ?? "default string"; // "" (''이 유지된다)

    var count = 0 || 10; // 10 (0이 덮어써진다)
    var count = 0 ?? 10; // 0 (0이 유지된다)
    ```
