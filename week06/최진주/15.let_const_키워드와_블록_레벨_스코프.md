# 15장. let, const 키워드와 블록 레벨 스코프

- ES6에서 var의 문제를 보완하기 위해 let, const 도입
- let, const는 블록 레벨 스코프, 같은 스코프 내 중복 선언 금지
- 호이스팅은 발생하지만 초기화 전까지 TDZ로 접근 불가
- const는 재할당 금지, 객체 내부 변경은 가능
- 기본은 const, 재할당이 필요할 때만 let, var는 사용 지양

---

## var의 문제점

- 중복 선언 허용 → 기존 값을 의도치 않게 덮어씀
- 함수 레벨 스코프 → if, for 블록을 스코프로 인정하지 않음
- 블록 안 var 선언은 바깥 스코프 변수와 동일하게 동작
- 선언 전 접근 시 undefined 반환 → 에러 없이 버그가 숨음

```js
if (true) {
  var x = 1;
  let y = 2;
}
console.log(x); // 1
console.log(y); // ReferenceError: y is not defined
```

---

## 변수 생성 단계와 TDZ

- 변수 생성은 선언 단계와 초기화 단계로 구성
- 초기화: 변수에 undefined를 할당해 접근 가능한 상태로 만드는 것

| 구분 | 선언 단계 | 초기화 단계 |
|---|---|---|
| var | 런타임 이전 | 선언 단계와 동시 (undefined) |
| let, const | 런타임 이전 | 선언문 도달 시점 |

- TDZ(Temporal Dead Zone): 스코프 시작부터 선언문 도달 전까지의 구간
- TDZ 구간에서 접근 시 ReferenceError 발생
- 호이스팅이 없는 것이 아니라 초기화 시점이 늦은 것

```js
let foo = 1;
{
  console.log(foo); // ReferenceError
  let foo = 2;
}
```

- 호이스팅이 없다면 바깥 foo의 값 1 출력
- 블록 안 foo가 호이스팅된 상태에서 초기화 전이라 TDZ에 걸려 에러 발생

## 반복문과 블록 레벨 스코프

```js
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i)); // 3, 3, 3
}

for (let j = 0; j < 3; j++) {
  setTimeout(() => console.log(j)); // 0, 1, 2
}
```

- setTimeout 콜백은 반복문이 모두 끝난 뒤 실행
- var: 변수 i 하나를 모든 콜백이 공유, 실행 시점의 i는 이미 3
- let: 반복마다 새로운 스코프와 새로운 j 생성
- 각 콜백은 자기가 만들어진 반복의 j를 참조 (클로저, 24장)

## const

- 선언과 동시에 초기화 필수, 생략 시 SyntaxError
- 재할당 금지: 원시값, 객체 구분 없이 모든 재할당에 TypeError
- 변수에 저장된 참조값이 고정되는 것이지 값 자체가 불변인 것은 아님

```js
const cart = { count: 1 };
cart.count = 2;      // 가능, 같은 객체의 프로퍼티 변경
console.log(cart);   // { count: 2 }
cart = { count: 3 }; // TypeError, 새 객체 재할당
```

- 객체까지 변경을 막으려면 Object.freeze 사용
- Object.freeze는 얕은 동결, 중첩 객체 내부는 변경 가능
- 변하지 않는 상수는 대문자 스네이크 케이스 관례 (MAX_COUNT)

## 전역 객체와의 관계

```js
// 브라우저 일반 스크립트 기준
var a = 1;
let b = 2;
console.log(window.a); // 1
console.log(window.b); // undefined
console.log(b);        // 2
```

- var 전역 변수: 전역 객체(window)의 프로퍼티가 됨
- let, const 전역 변수: window 프로퍼티가 아님
- 전역 렉시컬 환경의 선언적 환경 레코드에 별도 저장 (23장)
- window 프로퍼티는 아니지만 전역 변수이므로 어디서든 접근 가능

## var, let, const 비교

| 구분 | var | let | const |
|---|---|---|---|
| 스코프 | 함수 | 블록 | 블록 |
| 중복 선언 | 허용 | 금지 | 금지 |
| 재할당 | 가능 | 가능 | 불가 |
| 선언 전 접근 | undefined | ReferenceError | ReferenceError |
| 전역 선언 시 window 프로퍼티 | O | X | X |
