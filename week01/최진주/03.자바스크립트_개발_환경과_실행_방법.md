# 3장. 자바스크립트 개발 환경과 실행 방법

## 브라우저 vs Node.js
둘 다 JS 엔진이 있어서 JS를 실행할 수 있지만 **목적이 달라서 쓸 수 있는 API가 다름**

| | 브라우저 | Node.js |
| --- | --- | --- |
| 목적 | 웹 페이지 렌더링 | 브라우저 밖에서 JS 실행 |
| DOM API | O | X |
| 파일 시스템 | X (보안 때문) | O |

- Node에서 `document` 쓰면 에러남

## 브라우저 개발자 도구
- Elements: DOM/CSS 확인
- Console: 에러, `console.log` 확인. 에러 나면 여기부터 보기
- Sources: 디버깅 (브레이크포인트 걸고 한 줄씩 실행)
- Network: 요청/응답, 성능
- Application: 스토리지, 쿠키

## Node.js & npm
- Node.js: V8 기반 JS 런타임
- npm: 패키지 매니저 (패키지 저장소 + 설치/관리 CLI)
- 설치는 안정성이 높은 **LTS** 버전으로
