# 1장. 프로그래밍

## 프로그래밍이란
- 컴퓨터한테 실행을 요구하는 커뮤니케이션
- **문제 해결 능력**이 가장 중요
- 문제를 명확하게 이해 → 복잡함을 단순하게 분해 → 자료를 정리하고 구분 → 순서에 맞게 행위를 배열
- 컴퓨터는 모호한 요구사항을 이해할 수 없으니 컴퓨터 입장에서 쪼개서 생각하는 **컴퓨팅 사고**가 중요

> 프로그래밍 = 요구사항을 분석해서 **자료구조와 함수의 집합으로 바꾸고, 그 흐름을 제어하는 것**

## 구문과 의미
- 문법(구문)이 맞아도 **의미**가 없으면 쓸모없음

```js
const number = 'string';
console.log(number * number); // NaN
```

- 에러는 안 나지만 `number`에 문자열을 넣은 건 말이 안 됨
- 결국 언어 문법을 외우는 것보다 "이 코드가 뭘 하려는지"가 명확한 게 중요
- 작성된 코드 = 해결 방안의 구체적 구현물
- 문제를 해결할 수 있어야 의미 있는 코드가 됨
